## 七、常见坑点汇总（全章节积累）

**3.1 大模型调用**：
1. API Key 泄露 — 必须用环境变量
2. stream=True 时 response.json() 报错
3. max_tokens 太小回复截断
4. Ollama 端口 11434 必须写

**3.3 Streamlit**：
5. set_page_config 必须第一行
6. 普通变量不保留，要用 session_state
7. **session_state key 拼写必须一致**（"messages" vs "message"）

**3.4 智能伴侣**：
8. 流式后忘存 full_response → AI 失忆
9. **点击按钮后不 st.rerun() → 要"点两遍"**（v4 已修复）
10. 列表按钮 key 必须唯一（f"load_{session}"）
11. 删除当前会话不重置 → 指向不存在的文件

**3.5 文件操作**：
12. "w" 会清空文件，追加用 "a"
13. write() 不自动换行
14. Windows 中文必须 encoding="utf-8"、JSON 要 ensure_ascii=False
15. json.dump vs json.dumps 容易搞混
