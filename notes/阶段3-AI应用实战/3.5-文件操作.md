## 一、读文件

### 1. 三步走：打开 → 读取 → 关闭

```python
# 1. 打开文件（"r" = 只读，encoding 指定编码）
f = open("./resources/古诗.txt", "r", encoding="utf-8")

# 2. 读取内容（三种方式）
content = f.read()            # 读取所有内容（字符串）
content_list = f.readlines()  # 按行读取，返回列表（每行一个元素）
line = f.readline()           # 读取一行

# 3. 关闭文件（必须！释放资源）
f.close()
```

### 2. 遍历文件行

```python
f = open("./resources/古诗.txt", "r", encoding="utf-8")

content_list = f.readlines()
for line in content_list:
    print(line.strip())   # strip() 去掉每行首尾的空格和换行

f.close()
```

> 💡 `readlines()` 返回的每行末尾带 `\n`，用 `.strip()` 去掉换行符，避免打印时多出空行。

### 3. 文件不存在会报错

```python
f = open("./resources/不存在的文件.txt", "r", encoding="utf-8")
# ❌ FileNotFoundError: [Errno 2] No such file or directory
```

## 二、写文件

### 1. 三步走：打开 → 写入 → 关闭

```python
# 1. 打开文件（"w" = 只写，文件不存在自动创建，存在则覆盖清空）
f = open("./resources/静夜诗.txt", "w", encoding="utf-8")

# 2. 写入内容（write 不会自动换行，需要自己加 \n）
f.write("静夜诗(李白)\n\n")
f.write("床前明月光\n")
f.write("疑是地上霜\n")
f.write("举头望明月\n")
f.write("低头思故乡\n")

# 3. 关闭文件
f.close()
```

> ⚠️ `write()` **不会自动换行**，必须手动写 `\n`。

### 2. 文件打开模式速查

| 模式 | 含义 | 文件不存在 | 写操作 |
|:--:|------|:--:|------|
| `"r"` | 只读 | 报错 | ❌ |
| `"w"` | 只写（覆盖） | 自动创建 | ✅ 清空后写 |
| `"a"` | 追加 | 自动创建 | ✅ 末尾追加 |
| `"r+"` | 读写 | 报错 | ✅ |
| `"w+"` | 读写（覆盖） | 自动创建 | ✅ |
| `"a+"` | 读写（追加） | 自动创建 | ✅ |

```python
# "w"：覆盖（第二次运行会清空重写）
with open("笔记.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n")

# "a"：追加（在末尾继续写，不清空）
with open("笔记.txt", "a", encoding="utf-8") as f:
    f.write("追加的第二行\n")
```

## 三、with 语句（上下文管理器）——推荐写法

> ⚠️ **预习内容**：`with` 是课程后续（112-113 集）的重点，这里提前补充，因为它比手动 `close()` 更安全、更推荐。

```python
# ❌ 手动 close 的写法：如果 read() 中间报错，文件不会关闭
f = open("./resources/古诗.txt", "r", encoding="utf-8")
content = f.read()
f.close()

# ✅ with 写法：缩进块结束自动关闭，异常也安全
with open("./resources/古诗.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)
# 缩进结束，文件自动关闭，无需手动 close()
```

> 💡 **`with` 是 Python 的"自动打扫"**——进入块时打开文件，块结束（无论正常还是异常）都自动关闭。这是 Python 推荐的写法，比手动 `close()` 更安全。

## 四、编码

```python
# 读中文文件必须指定 utf-8，否则 Windows 默认 gbk 可能乱码/报错
f = open("古诗.txt", "r", encoding="utf-8")

# 写中文文件同样指定 utf-8
f = open("新文件.txt", "w", encoding="utf-8")
```

> ⚠️ Windows 下读写中文文件**必须写 `encoding="utf-8"`**，否则可能遇到 `UnicodeDecodeError`（读）或乱码（写）。

## 五、JSON 文件操作（第 112 集）

> 📌 智能伴侣的对话历史要存到文件，用的就是 JSON 格式。JSON 能把 Python 的 `dict` / `list` 变成文本存盘，读回来还能还原成原来的数据结构——这是会话持久化的核心技术。

### 1. 写入（json.dump）

```python
import json

# 要保存的数据：可以是 dict / list / 嵌套结构
user = {
    "name": "mosifu",
    "age": 18,
    "gender": "男",
    "hobbies": ["游泳", "跑步"]
}

# 打开文件写入（"w" 覆盖写，不存在自动创建）
with open("./resources/user.json", "w", encoding="utf-8") as f:
    json.dump(user, f, ensure_ascii=False, indent=2)
```

> 💡 `ensure_ascii=False`：默认 True 会把非 ASCII 字符（中文）转成 `\uXXXX` 转义，存进去全是乱码一样的东西；设成 False 中文原样保存，方便查看。
> 💡 `indent=2`：写入时加缩进格式化，文件可读性好。不写就是一整行挤在一起。

### 2. 读取（json.load）

```python
import json

# 读取 JSON 文件，还原成原来的 Python 数据结构
with open("./resources/user.json", "r", encoding="utf-8") as f:
    user = json.load(f)
    print(user)        # {'name': 'mosifu', 'age': 18, ...}
    print(type(user))  # <class 'dict'>
```

### 3. 四种函数速查

| 操作 | 函数 | 说明 |
|------|------|------|
| 序列化（dict→JSON 写入文件） | `json.dump(数据, 文件)` | 直接写文件 |
| 反序列化（文件→dict） | `json.load(文件)` | 从文件读 |
| 序列化（dict→JSON 字符串） | `json.dumps(数据)` | 返回字符串 |
| 反序列化（字符串→dict） | `json.loads(字符串)` | 从字符串读 |

### 4. 在智能伴侣中的应用

```python
# 保存整个会话（dict 里嵌套 messages 列表）
session_data = {
    "nick_name": st.session_state.nick_name,
    "nature": st.session_state.nature,
    "current_session": st.session_state.current_session,
    "messages": st.session_state.messages,
}
with open(f'./resources/sessions/{st.session_state.current_session}.json', 'w', encoding="utf-8") as f:
    json.dump(session_data, f, ensure_ascii=False, indent=2)

# 读取会话还原
with open(f'./resources/sessions/{session_name}.json', 'r', encoding="utf-8") as f:
    session_data = json.load(f)
    st.session_state.messages = session_data["messages"]
```

## 常见坑点

1. **忘关文件** — `f.close()` 漏写，文件句柄泄漏（`with` 可避免）
2. **`"w"` 会清空** — 误用 `"w"` 打开已有文件会清空内容，想追加用 `"a"`
3. **`write()` 不换行** — 必须手动加 `\n`
4. **中文编码** — Windows 下必须 `encoding="utf-8"`，JSON 中文要 `ensure_ascii=False`
5. **读不存在的文件** — `"r"` 模式会 `FileNotFoundError`，写模式 `"w"`/`"a"` 会自动创建
6. **`read()` vs `readlines()`** — `read()` 返回整个字符串，`readlines()` 返回行列表
7. **`json.dump` vs `json.dumps`** — 别搞混：`dump` 直接写文件，`dumps` 返回字符串；读取对应 `load` / `loads`

---

## 小结

1. **读文件**：`open(...,"r")` → `read()/readlines()` → `close()`
2. **写文件**：`open(...,"w")` → `write()`（手动加 `\n`）→ `close()`
3. **推荐用 `with`**：自动关闭，异常安全
4. **模式区分**：`"r"` 只读 / `"w"` 覆盖写 / `"a"` 追加写
5. **JSON 持久化**：`json.dump/load` 读写结构化数据，智能伴侣用它把整个会话（昵称+性格+messages）存成 `.json` 文件，实现多会话管理
