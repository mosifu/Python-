## 一、读文件

### 1. 三步走：打开 → 读取 → 关闭

```python
# 1. 打开文件（"r" = 只读，encoding 指定编码）
f = open("./resources/古诗.txt", "r", encoding="utf-8")

# 2. 读取内容（三种方式）
content = f.read()            # 读取所有内容（字符串）
content_list = f.readlines()  # 按行读取，返回列表（每行一个元素）
line = f.readline()           # 读取一行

# 3. 关闭文件（必须！释放资源）
f.close()
```

### 2. 遍历文件行

```python
f = open("./resources/古诗.txt", "r", encoding="utf-8")

content_list = f.readlines()
for line in content_list:
    print(line.strip())   # strip() 去掉每行首尾的空格和换行

f.close()
```

> 💡 `readlines()` 返回的每行末尾带 `\n`，用 `.strip()` 去掉换行符，避免打印时多出空行。

### 3. 文件不存在会报错

```python
f = open("./resources/不存在的文件.txt", "r", encoding="utf-8")
# ❌ FileNotFoundError: [Errno 2] No such file or directory
```

## 二、写文件

### 1. 三步走：打开 → 写入 → 关闭

```python
# 1. 打开文件（"w" = 只写，文件不存在自动创建，存在则覆盖清空）
f = open("./resources/静夜诗.txt", "w", encoding="utf-8")

# 2. 写入内容（write 不会自动换行，需要自己加 \n）
f.write("静夜诗(李白)\n\n")
f.write("床前明月光\n")
f.write("疑是地上霜\n")
f.write("举头望明月\n")
f.write("低头思故乡\n")

# 3. 关闭文件
f.close()
```

> ⚠️ `write()` **不会自动换行**，必须手动写 `\n`。

### 2. 文件打开模式速查

| 模式 | 含义 | 文件不存在 | 写操作 |
|:--:|------|:--:|------|
| `"r"` | 只读 | 报错 | ❌ |
| `"w"` | 只写（覆盖） | 自动创建 | ✅ 清空后写 |
| `"a"` | 追加 | 自动创建 | ✅ 末尾追加 |
| `"r+"` | 读写 | 报错 | ✅ |
| `"w+"` | 读写（覆盖） | 自动创建 | ✅ |
| `"a+"` | 读写（追加） | 自动创建 | ✅ |

```python
# "w"：覆盖（第二次运行会清空重写）
with open("笔记.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n")

# "a"：追加（在末尾继续写，不清空）
with open("笔记.txt", "a", encoding="utf-8") as f:
    f.write("追加的第二行\n")
```

## 三、with 语句（上下文管理器）——推荐写法

> ⚠️ **预习内容**：`with` 是课程后续（112-113 集）的重点，这里提前补充，因为它比手动 `close()` 更安全、更推荐。

```python
# ❌ 手动 close 的写法：如果 read() 中间报错，文件不会关闭
f = open("./resources/古诗.txt", "r", encoding="utf-8")
content = f.read()
f.close()

# ✅ with 写法：缩进块结束自动关闭，异常也安全
with open("./resources/古诗.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)
# 缩进结束，文件自动关闭，无需手动 close()
```

> 💡 **`with` 是 Python 的"自动打扫"**——进入块时打开文件，块结束（无论正常还是异常）都自动关闭。这是 Python 推荐的写法，比手动 `close()` 更安全。

## 四、编码

```python
# 读中文文件必须指定 utf-8，否则 Windows 默认 gbk 可能乱码/报错
f = open("古诗.txt", "r", encoding="utf-8")

# 写中文文件同样指定 utf-8
f = open("新文件.txt", "w", encoding="utf-8")
```

> ⚠️ Windows 下读写中文文件**必须写 `encoding="utf-8"`**，否则可能遇到 `UnicodeDecodeError`（读）或乱码（写）。

## 五、JSON 文件操作（智能伴侣持久化准备）

> ⚠️ **预习内容**：JSON 持久化是课程后续（112-113 集）的内容，这里提前补充，智能伴侣的会话保存会用到。

智能伴侣的对话历史要存到文件，通常用 JSON 格式：

```python
import json

# 保存：dict/list → JSON 字符串 → 写入文件
messages = [
    {"role": "user", "content": "你好"},
    {"role": "ai", "content": "你好呀~"},
]

with open("history.json", "w", encoding="utf-8") as f:
    json.dump(messages, f, ensure_ascii=False, indent=2)

# 读取：文件 → JSON 字符串 → dict/list
with open("history.json", "r", encoding="utf-8") as f:
    loaded = json.load(f)

print(loaded)
```

| 操作 | 函数 | 说明 |
|------|------|------|
| 序列化（dict→JSON写入文件） | `json.dump(数据, 文件)` | 直接写文件 |
| 反序列化（文件→dict） | `json.load(文件)` | 从文件读 |
| 序列化（dict→JSON字符串） | `json.dumps(数据)` | 返回字符串 |
| 反序列化（字符串→dict） | `json.loads(字符串)` | 从字符串读 |

> 💡 `ensure_ascii=False` 让中文正常显示（默认 True 会转成 `\uXXXX` 转义）。这是智能伴侣 112-113 集要做的事：把 `st.session_state.messages` 存进 JSON 文件实现持久化。

## 常见坑点

1. **忘关文件** — `f.close()` 漏写，文件句柄泄漏（`with` 可避免）
2. **`"w"` 会清空** — 误用 `"w"` 打开已有文件会清空内容，想追加用 `"a"`
3. **`write()` 不换行** — 必须手动加 `\n`
4. **中文编码** — Windows 下必须 `encoding="utf-8"`
5. **读不存在的文件** — `"r"` 模式会 `FileNotFoundError`，写模式 `"w"`/`"a"` 会自动创建
6. **`read()` vs `readlines()`** — `read()` 返回整个字符串，`readlines()` 返回行列表

---

## 小结

1. **读文件**：`open(...,"r")` → `read()/readlines()` → `close()`
2. **写文件**：`open(...,"w")` → `write()`（手动加 `\n`）→ `close()`
3. **推荐用 `with`**：自动关闭，异常安全
4. **模式区分**：`"r"` 只读 / `"w"` 覆盖写 / `"a"` 追加写
5. **JSON 持久化**：`json.dump/load` 读写结构化数据，智能伴侣用它保存对话历史
