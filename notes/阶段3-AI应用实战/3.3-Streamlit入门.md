## 一、什么是 Streamlit

- **是什么**：Streamlit 是 Python 的 Web 应用框架，让你**只用 Python 代码**就能把脚本变成网页应用，无需写 HTML/CSS/JS。
- **Java 对比**：≈ 一个极简的 Spring Boot + 前端框架合体，但**不需要 Controller、不需要模板引擎**，写普通 Python 脚本就行。

### 核心特点

| 特点 | 说明 |
|------|------|
| 纯 Python | 不需要写 HTML/CSS/JavaScript |
| 自动重跑 | 每次交互，整个脚本从头执行一遍 |
| 秒级热更新 | 改代码保存，浏览器自动刷新 |
| 内置组件 | 输入框/按钮/图表/表格等开箱即用 |

### 安装与运行

```bash
# 安装
pip install streamlit

# 运行（注意是 streamlit run 不是 python）
streamlit run 你的程序.py
```

> 💡 运行后终端会显示本地地址（默认 `http://localhost:8501`），浏览器打开即可。

## 二、页面配置 `st.set_page_config`

```python
import streamlit as st

st.set_page_config(
    page_title="AI智能伴侣",         # 浏览器标签页标题
    page_icon="🤖",                  # 浏览器标签页图标（emoji）
    layout="wide",                   # 页面布局：wide（宽屏）/ centered（居中）
    initial_sidebar_state="expanded", # 侧边栏初始状态：expanded/collapsed/auto
    menu_items={}                    # 右上角菜单自定义
)
```

> ⚠️ `st.set_page_config()` **必须是脚本中第一个 Streamlit 命令**，且只能调用一次。

## 三、文本元素

```python
st.title("这里是一级标题")      # 最大标题
st.header("这里是二级标题")     # 次大标题
st.subheader("这是三级标题")    # 小标题
st.write("普通文本")           # 万能输出（文本/数据/图表都行）
st.markdown("**加粗** *斜体*") # Markdown 语法
```

## 四、媒体元素

```python
# 图片
st.image("./resources/Yidao.jpg")

# 音频
st.audio("./resources/音乐.mp3")

# 视频
st.video("./resources/视频.mp4")

# Logo（页面顶部/侧边栏）

```

> ⚠️ 媒体文件路径是**相对启动命令的工作目录**，建议用绝对路径或 `os.path` 拼接，避免不同目录启动时报 `FileNotFoundError`。

## 五、数据元素

```python
# 静态表格
student_data = {
    "姓名": ["王林", "李慕婉", "贝罗", "莫厉海", "石萧"],
    "语文": [98, 90, 59, 29, 80],
    "总分": [285, 257, 211, 158, 181]
}

# 交互表格（支持排序/筛选，适合大数据）
import pandas as pd
st.dataframe(pd.DataFrame(student_data))
```

## 六、表单控件

```python
# 普通输入框
name = st.text_input("请输入姓名")
st.write(f"您输入的姓名为: {name}")

# 密码输入框（type="password" 会打码显示）
password = st.text_input("请输入密码", type="password")
st.write(f"您输入的密码为: {password}")

# 单选按钮（index 是默认选中项下标）
gender = st.radio("请输入您的性别", ["男", "女", "未知"], index=2)
st.write(f"您的性别为: {gender}")

# 下拉选择框
city = st.selectbox("请选择城市", ["北京", "上海", "广州"])

# 多选
hobbies = st.multiselect("请选择爱好", ["篮球", "游泳", "编程", "音乐"])

# 按钮
if st.button("点击我"):
    st.write("按钮被点击了！")

# 滑块
age = st.slider("选择年龄", 0, 100, 25)

# 文本域（多行输入）
note = st.text_area("备注", "默认内容")
```

## 七、Streamlit 运行机制（重要！）

Streamlit 的核心机制是 **每次交互都重跑整个脚本**：

```
用户点击/输入
    │
    ▼
整个 .py 脚本从头到尾执行一遍
    │
    ├── 重新渲染所有组件
    ├── 全局变量被重新创建（除非用 st.session_state）
    └── 生成新的网页
```

**这个机制带来的两个关键点**：

1. **普通变量不保留**：脚本重跑后，普通变量全部重新初始化，值会丢失
2. **`st.session_state` 才保留**：跨重跑保存数据的唯一"保险箱"

```python
# 普通变量：每次重跑都是新值
count = 0            # 每次重跑都变回 0

# session_state：跨重跑保留
if "count" not in st.session_state:
    st.session_state.count = 0
st.session_state.count += 1   # 每次重跑累加
st.write(f"这是第 {st.session_state.count} 次重跑")
```

> ⚠️ **`st.session_state` 的 key 必须前后一致**：初始化用 `"messages"`，读取也必须 `"messages"`，拼错一个字母就会导致每次重跑都重新初始化（历史丢失）。

## 八、侧边栏 `st.sidebar`

```python
# 方式1：with 语句包裹
with st.sidebar:
    st.header("设置")
    name = st.text_input("昵称")
    nature = st.text_input("性格")

# 方式2：直接 st.sidebar.xxx
st.sidebar.header("设置")
st.sidebar.slider("温度", 0.0, 2.0, 0.7)
```

## 常见坑点

1. **`set_page_config` 必须第一行** — 放后面会报错
2. **普通变量不保留** — 跨重跑要用 `st.session_state`
3. **`session_state` key 拼写一致** — `"messages"` 和 `"message"` 是两个不同的 key
4. **相对路径依赖工作目录** — 用 `os.path.join(os.path.dirname(__file__), ...)` 更稳
5. **`st.chat_message` 的角色名** — 用标准名 `"user"`/`"assistant"`，自定义名（如 `"ai"`）显示可能不理想

---

## 小结

1. **Streamlit = 纯 Python 写 Web**，`streamlit run xxx.py` 启动，浏览器自动刷新
2. **交互组件**：`text_input`/`radio`/`selectbox`/`button`/`slider` 等，配合 `st.write` 输出
3. **核心机制**：每次交互重跑整个脚本，`st.session_state` 是跨重跑保存数据的唯一方式，key 必须前后一致
