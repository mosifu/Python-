## 类与对象

> 📺 **对应课程**：第 77–79 集

### 1. 什么是类和对象

- **是什么**：类是图纸（设计图），对象是按图纸造出来的实物。一个 `Car` 类可以造出无数辆车。
- **Java 对比**：
  - 相似点：`class`/对象/属性/方法 概念完全一致
  - 不同点：Python **无 `public/private`**、`self` 必须显式写、类名用大驼峰

```python
# 定义类 - 大驼峰命名法
class Car:
    pass

# 创建对象
c1 = Car()
# 不推荐：动态添加属性（Java 做不到，Python 可以但不规范）
c1.color = "red"
c1.brand = "BMW"
print(c1.brand)          # BMW
print(c1.__dict__)       # {'color': 'red', 'brand': 'BMW'} 所有属性字典
```

> ⚠️ 动态添加属性虽能用，但**不推荐**--应该用 `__init__` 规范化。

### 2. `__init__` 与 `self`

```python
class Car:
    # __init__ 在创建对象时自动调用（≈ Java 构造方法）
    # self 是第一个参数，表示当前对象（≈ Java 的 this，但必须显式写）
    def __init__(self, color, brand, name, price):
        self.color = color      # self.属性 = 参数
        self.brand = brand
        self.name = name
        self.price = price
        print("Car 对象初始化完毕")

# 创建对象时传参（self 自动传入，不用手写）
c1 = Car("蓝色", "BMW", "X5", 1000000)
c2 = Car("黄色", "XIAOMI", "SU7", 1000000)
print(c1.brand)    # BMW
```

**Java 对比**：

| | Python | Java |
|------|--------|------|
| 构造方法 | `__init__` | 与类同名 |
| this/self | `self`（必须显式写第一个参数） | `this`（隐式） |
| 创建对象 | `Car("蓝", "BMW")` | `new Car("蓝", "BMW")` |

### 3. 实例方法

```python
class Car:
    def __init__(self, color, brand, name, price):
        self.color = color
        self.brand = brand
        self.name = name
        self.price = price

    # 实例方法 - 第一个参数永远是 self
    def running(self):
        print(f"{self.brand}{self.name}正在高速行驶...")

    def total_price(self, discount, rate):
        """计算提车价 = 折扣价 + 税"""
        return discount * self.price + rate * self.price

c1 = Car("蓝色", "BMW", "X5", 1000000)
c1.running()                                    # BMWX5正在高速行驶...
print(f"提车价: {c1.total_price(0.9, 0.1)}")     # 1000000.0
```

## 魔法方法

> 📺 **对应课程**：第 80 集

- **是什么**：魔法方法是 Python 提供的 `__xxx__` 形式特殊方法，**无需手动调用**，解释器在合适时机自动调用。
- **Java 对比**：≈ `toString()`/`equals()`/`compareTo()` 等方法重写

| 魔法方法 | 触发时机 | Java 对应 |
|---------|---------|----------|
| `__init__` | 创建对象时 | 构造方法 |
| `__str__` | `print(对象)` 时 | `toString()` |
| `__lt__` | `obj1 < obj2` 时 | `compareTo()` |
| `__eq__` | `obj1 == obj2` 时 | `equals()` |

```python
class Car:
    def __init__(self, color, brand, name, price):
        self.color = color
        self.brand = brand
        self.name = name
        self.price = price

    # print(对象) 时自动调用
    def __str__(self):
        return f"{self.color} {self.brand} {self.name} {self.price}"

    # obj1 < obj2 时自动调用
    def __lt__(self, other):
        return self.price < other.price

    # obj1 == obj2 时自动调用
    def __eq__(self, other):
        return (self.price == other.price and
                self.color == other.color and
                self.brand == other.brand and
                self.name == other.name)

c1 = Car("蓝色", "BMW", "X5", 1000000)
c2 = Car("蓝色", "BMW", "X5", 1000000)

print(c1)           # 蓝色 BMW X5 1000000（触发 __str__）
print(c1 == c2)     # True（触发 __eq__）
print(c1 > c2)      # False（触发 __lt__）
```

> 💡 不写 `__str__` 时，`print(c1)` 输出 `<__main__.Car object at 0x...>`，写了就输出友好信息。

## 实例属性与类属性

> 📺 **对应课程**：第 81 集

```python
class Car:
    # 类属性 - 所有实例共享（写在类里、方法外）
    wheel = 4        # 轮胎数
    tax_rate = 0.1   # 购置税率

    def __init__(self, color, brand, name, price):
        # 实例属性 - 每个对象独有（写在 __init__ 里）
        self.color = color
        self.brand = brand
        self.name = name
        self.price = price
        self.wheel = 2   # ⚠️ 创建实例属性，遮蔽了类属性！

c1 = Car("蓝色", "BMW", "X5", 1000000)
print(c1.wheel)     # 2（先找实例属性，找到就用）
print(Car.wheel)    # 4（通过类名访问类属性）
```

**查找规则**：`实例.属性` -> 先找实例属性 -> 没有再找类属性

| | 类属性 | 实例属性 |
|------|--------|---------|
| 定义位置 | 类内、方法外 | `__init__` 内 `self.xxx` |
| 共享 | ✅ 所有实例共享 | ❌ 各实例独有 |
| 访问 | `类名.属性` 或 `实例.属性` | `实例.属性` |
| Java 对应 | `static` 静态字段 | 普通字段 |

## 综合案例

> 💡 以下两个案例来自学习者的实战练习，用 OOP 重构了 2.3 的购物车和教务系统。

### 案例1：购物车系统（OOP 版）

```python
class Goods:
    """商品类"""
    def __init__(self, name, price, num):
        self.name = name
        self.price = price
        self.num = num

    def __str__(self):
        return f"商品名称:{self.name}, 商品价格:{self.price}, 商品数量:{self.num}"

    def update_goods(self, price=None, num=None):
        """修改商品信息（None 表示不修改该项）"""
        if price is not None:
            self.price = price
        if num is not None:
            self.num = num


class ShoppingCart:
    """购物车系统类"""
    system_version = "1.0.1"       # 类属性
    system_name = "购物车管理系统"

    def __init__(self):
        self.cart_list = []        # 实例属性：购物车列表

    def add_cart(self):
        name = input("请输入商品名称: ")
        for good in self.cart_list:
            if good.name == name:
                print("当前商品已存在,添加失败!")
                return
        price = float(input("请输入商品价格: "))
        num = int(input("请输入商品数量: "))
        self.cart_list.append(Goods(name, price, num))
        print("商品添加成功~")

    def update_cart(self):
        name = input("请输入商品名称: ")
        for good in self.cart_list:
            if good.name == name:
                print(f"当前: {good}")
                price = float(input("请输入商品价格: "))
                num = int(input("请输入商品数量: "))
                good.update_goods(price, num)
                print(f"修改后: {good}")
                return
        print("商品信息不存在,修改失败!")

    def delete_cart(self):
        name = input("请输入商品名称: ")
        for good in self.cart_list:
            if good.name == name:
                self.cart_list.remove(good)
                print("删除商品信息成功~")
                return
        print("商品信息不存在,删除失败!")

    def print_cart(self):
        for good in self.cart_list:
            print(good)

    def run(self):
        print(f"进入购物车系统 V{ShoppingCart.system_version}")
        while True:
            print("\n# 1.添加  2.修改  3.删除  4.查询  5.退出 #")
            choice = input("请输入操作(1-5): ")
            try:
                match choice:
                    case "1": self.add_cart()
                    case "2": self.update_cart()
                    case "3": self.delete_cart()
                    case "4": self.print_cart()
                    case "5": print("退出系统!bye~"); break
                    case _:   print("输入数字不在范围内!")
            except ValueError:
                print("输入数值有误,请重新输入!")


if __name__ == '__main__':
    ShoppingCart().run()
```

## 常见坑点

1. **`self` 必须显式写** - Java 的 `this` 是隐式的，Python 第一个参数必须是 `self`
2. **`__init__` 不是构造方法** - 它是初始化方法，对象已创建后才调用
3. **类名大驼峰** - `Student` 不是 `student`，`Goods` 不是 `goods`
4. **实例属性遮蔽类属性** - `self.wheel = 2` 会创建实例属性，不影响类属性
5. **`__str__` 必须返回字符串** - 不能 `print`，要 `return`
6. **`update(self, price=None)` 模式** - 用 None 做可选参数，避免 0 被误判为"不修改"

---

## 小结

1. **类与对象**：`class` 定义图纸，`类()` 造对象；`__init__` 初始化，`self` 代表当前对象
2. **魔法方法**：`__str__`（print 时）、`__lt__`（比较大小）、`__eq__`（判等）自动触发
3. **属性**：类属性所有实例共享（≈ static），实例属性各对象独有；查找时先实例后类
4. **OOP 设计**：数据 + 行为封装进类，比字典版更易扩展和维护
