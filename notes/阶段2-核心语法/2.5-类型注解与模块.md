## 类型注解

> 📺 **对应课程**：第 71–72 集

### 1. 什么是类型注解

- **是什么**：类型注解就像给快递贴标签--标签写的是"易碎品"（类型），但快递员（解释器）不一定按标签处理，只是**提示**。
- **Java 对比**：
  - 相似点：写法上像 Java 的显式类型声明
  - 不同点：**Python 注解只是提示，不强制**（运行时仍是动态类型）；Java 是编译期强制检查

```python
# 无注解 - Python 默认风格
a = 1
b = 2.4
c = "Hello World"
names = ['A', 'B', 'C']

# 有注解 - 变量名: 类型 = 值
a1: int = 2
b2: float = 2.5
hobby: str = "Python"
flag2: bool = True
d1: None = None
```

> ⚠️ **类型注解不改变 Python 动态类型的本质**。注解写 `int`，你照样能赋字符串，解释器不报错（除非用 mypy 等工具检查）。

### 2. 容器类型注解

```python
# 列表 - list[元素类型]
names: list[str | int] = ["A", 23, "B"]     # 元素可以是 str 或 int

# 集合 - set[元素类型]
phones: set[str] = {"123", "234", "3535"}

# 字典 - dict[key类型, value类型]
options: dict[str | int, int] = {"count": 2, 555: 10}

# 元组 - tuple[类型1, 类型2, 类型3]（固定长度）
goods: tuple[str, int, float] = ("手机", 999, 1.3)
```

**Java 对比**：

| Python 注解 | Java 对应 |
|-------------|----------|
| `list[str]` | `List<String>` |
| `dict[str, int]` | `Map<String, Integer>` |
| `tuple[str, int]` | `Record<String, Integer>`（Java 14+） |
| `str \| int` | `Object`（Java 无联合类型，需重载） |

### 3. Union 联合类型 `|`

```python
# Python 3.10+ 用 | 表示"或"
x: int | str = 10      # 可以是 int 或 str
x = "hello"            # 合法

# 旧写法（3.10 前）：from typing import Union
# x: Union[int, str] = 10
```

### 4. 函数类型注解

```python
# 参数: 类型, 返回值 -> 类型
def circle_area_len(r: float) -> tuple[float, float]:
    """返回 (面积, 周长)"""
    return round(3.14 * r * r, 1), round(2 * 3.14 * r, 1)

area, length = circle_area_len(10)
print(area, length)   # 314.0 62.8
```

### 5. 实战：给订单计算器加注解

```python
def calc_order_cost(
    *args: tuple[str, float, int],   # 每个商品是 (名称, 单价, 数量)
    coupon: int = 0,
    score: int = 0,
    express: float = 0.0
) -> float:
    """计算订单总金额"""
    prices = [goods[1] * goods[2] for goods in args]
    total = sum(prices)
    if total >= 5000 and coupon <= total:
        total -= coupon
    if total >= 5000 and score // 100 <= total:
        total -= score // 100
    total += express
    return total

total = calc_order_cost(("手机", 4999, 2), ("茶叶", 78, 5),
                        coupon=10, score=4000, express=9.9)
print(total)  # 10347.9
```

### 6. 类型推断

- **是什么**：Python 解释器能自动推断变量类型，无需开发者显式声明。

```python
# 解释器自动推断：x 是 int
x = 10
# 等价于显式注解：x: int = 10
```

> 💡 类型注解主要给 **IDE 提示**（自动补全、错误警告）和 **mypy 静态检查**用，运行时不影响。

## 模块管理

> 📺 **对应课程**：第 73–76 集

### 1. 什么是模块

- **是什么**：模块就是一个 `.py` 文件，里面装着函数、变量、类，可以被别的文件导入复用。就像工具箱--把工具分类放好，要用的时候拿出来。
- **Java 对比**：
  - 相似点：`import module` ≈ `import com.xxx.Class`
  - 不同点：Python 模块就是 `.py` 文件，无需 `pom.xml`/`module-info.java`

### 2. 导入模块的三种方式

```python
# 方式1：import 模块名 - 调用要加模块名前缀
import random
print(random.randint(1, 100))

# 方式1变体：as 别名
import random as rd
print(rd.randint(1, 100))

# 方式2：from 模块 import 功能 - 直接用功能名
from random import randint
print(randint(1, 100))

# 方式2变体：as 别名
from random import randint as rint
print(rint(1, 100))

# 方式3：from 模块 import * - 导入全部（不推荐，易命名冲突）
from random import *
print(randint(1, 100))
```

**Java 对比**：

| Python | Java |
|--------|------|
| `import random` | `import java.util.Random;` |
| `random.randint(1,100)` | `new Random().nextInt(100)` |
| `from random import randint` | `import static java.util.Random.nextInt` |
| `import random as rd` | ❌ Java 无别名机制 |

### 3. 自定义模块

`my_fun.py`（模块文件）：

```python
# __all__ 控制 from...import * 能导入哪些
__all__ = ['PI', 'log_separator1', 'log_separator4']

PI = 3.14159
NAME = "mosifu"

def log_separator1():
    print("- " * 30)

def log_separator4():
    print("* " * 30)

# __name__ 是模块名；直接运行时为 "__main__"，被导入时为模块名
if __name__ == '__main__':
    log_separator1()   # 只有直接运行才执行，被导入不执行
```

`main.py`（使用模块）：

```python
# 导入整个模块
import my_fun as fun
print(fun.PI)
fun.log_separator1()

# 导入模块的功能
from my_fun import *        # 受 __all__ 控制，只导入 PI/log_separator1/log_separator4
print(PI)
log_separator1()
log_separator4()
```

### 4. `__all__` 与 `__name__`

| 变量 | 作用 | 示例 |
|------|------|------|
| `__all__` | 控制 `from module import *` 导入哪些 | `__all__ = ['PI', 'log_separator1']` |
| `__name__` | 当前模块名；直接运行为 `'__main__'` | `if __name__ == '__main__':` |
| `__version__` | 模块版本 | `__version__ = "1.0.0"` |
| `__author__` | 作者 | `__author__ = "mosifu"` |

> 💡 `if __name__ == '__main__':` 是 Python 的"入口"约定--直接运行才执行测试代码，被导入时不执行（避免副作用）。

### 5. package 包

当模块多了，用**文件夹（包）**组织。包就是含 `__init__.py` 的文件夹。

```
module_18/
├── module1/
│   ├── my_fun.py      # 模块
│   └── main.py
└── module2/           # 包
    ├── __init__.py    # 包的标识（可写 __all__/__version__）
    ├── my_fun.py
    └── my_var.py
```

`module2/__init__.py`：

```python
__all__ = ["my_fun", "my_var"]   # 控制 from package import * 导入哪些模块
__version__ = "1.0.0"
__author__ = "mosifu"
```

导入包中的模块：

```python
# 方式1：导入包中的模块
from module_18.module2 import my_fun
my_fun.log_separator1()

# 方式2：导入包中模块的功能
from module_18.module2.my_fun import log_separator4, log_separator2
log_separator4()

# 方式3：导入包下所有模块（需 __init__.py 配置 __all__）
from module_18.module2 import *
print(my_var.PI)
my_fun.log_separator4()
```

**Java 对比**：

| Python | Java |
|--------|------|
| 文件夹 + `__init__.py` = 包 | 文件夹 + `module-info.java` = 模块 |
| `from pkg.mod import func` | `import pkg.mod.Func` |
| `__init__.py` 可省略（3.3+ 命名空间包） | 必须有 `module-info.java` |

## 常见坑点

1. **类型注解不强制** - 写了 `x: int` 还是能赋字符串，运行时不报错
2. **`from module import *` 易冲突** - 多个模块同名功能会覆盖，生产代码不推荐
3. **`__all__` 只管 `*`** - `from mod import xxx` 不受 `__all__` 限制
4. **`if __name__ == '__main__'`** - 忘了写会导致模块被导入时执行测试代码
5. **包必须有 `__init__.py`**（传统包）- 否则可能识别不了（3.3+ 命名空间包除外）
6. **导入路径** - 相对路径（`from module2.my_fun import`）和绝对路径（`from day260711_Py.第二章...import`）不要混用

---

## 小结

1. **类型注解**：`变量: 类型 = 值`，容器用 `list[str]`/`dict[k,v]`/`tuple[...]`，联合用 `|`；仅提示不强制，给 IDE 和 mypy 用
2. **模块**：`.py` 文件即模块，`import`/`from...import`/`as` 三种导入；`__all__` 管 `*`，`__name__` 判入口
3. **包**：文件夹 + `__init__.py`，用点号路径导入 `from pkg.mod import func`
