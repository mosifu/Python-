## 一、CSV 是什么

- **是什么**：CSV（Comma-Separated Values，逗号分隔值）是纯文本表格文件，每行一条数据，字段间用逗号隔开。用 Excel 能直接打开成表格。
- **为什么爬虫用 CSV**：爬到的数据要持久化，CSV 比 JSON 更适合**表格型数据**（电影榜单、商品列表），且 Excel 可直接查看，无需第三方库。

```
姓名,年龄,性别,爱好
小王,18,男,踢足球
小李,23,女,Python
```

- **Java 对比**：≈ 手写一个轻量版 Excel 导出。Java 通常用 Apache Commons CSV 或 EasyExcel，Python 内置 `csv` 库零依赖。

## 二、原始文件方式读写 CSV（方式一）

最朴素的方式——把 CSV 当普通文本文件，手动拼逗号和换行：

```python
# 写：手动拼逗号 + \n
with open("csv_data/01.csv", 'w', encoding="utf-8") as f:
    f.write("姓名,年龄,性别,爱好\n")    # 表头
    f.write("小王,18,男,踢足球\n")       # 数据行
    f.write("小李,23,女,Python\n")

# 读：按行读，strip 去换行
with open("csv_data/01.csv", 'r', encoding="utf-8") as f:
    for line in f:
        print(line.strip())   # '小王,18,男,踢足球'
```

> ⚠️ **不推荐**：字段里含逗号（如 `足球,Java`）会破坏结构，要手动加引号转义。`csv` 库自动处理这些，所以实战用方式二。

## 三、csv 库：DictWriter / DictReader（方式二，推荐）

用**字典**读写，字段名即表头，最直观、最安全。

### 1. 写入（DictWriter）

```python
import csv

with open('csv_data/02.csv', 'w', newline='', encoding="utf-8") as f:
    # 1. 创建 writer，指定表头字段
    writer = csv.DictWriter(f, fieldnames=["姓名", "年龄", "性别", "爱好"])
    # 2. 写表头
    writer.writeheader()
    # 3. 逐行写数据（字典形式）
    writer.writerow({"姓名": "mo", "年龄": "23", "性别": "男", "爱好": "Java"})
    writer.writerow({"姓名": "lan", "年龄": "22", "性别": "女", "爱好": "化妆"})
```

| 步骤 | 作用 |
|------|------|
| `csv.DictWriter(f, fieldnames=[...])` | 创建 writer，fieldnames 定义列顺序 |
| `writer.writeheader()` | 写入表头行 |
| `writer.writerow(字典)` | 写一行 |
| `writer.writerows(字典列表)` | 批量写多行（电影案例用了这个） |

### 2. 读取（DictReader）

```python
with open('csv_data/02.csv', 'r', newline='', encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row)            # OrderedDict({'姓名': 'mo', '年龄': '23', ...})
        print(row["姓名"])    # 直接按字段名取值
```

> 💡 `DictReader` 自动把第一行当表头，每行返回字典，用 `row["字段名"]` 取值，比列表方式按 index 取值更安全可读。

### 3. 批量写入（writerows）—— 爬虫最常用

```python
# 爬虫攒一批数据后一次性写入
all_movies = [
    {"电影名": "肖申克的救赎", "评分": "9.7"},
    {"电影名": "霸王别姬", "评分": "9.6"},
]
with open('movies.csv', 'w', newline='', encoding='utf-8') as f:
    writer = csv.DictWriter(f, fieldnames=["电影名", "评分"])
    writer.writeheader()
    writer.writerows(all_movies)   # 一次写完整个列表
```

## 四、csv 库：writer / reader（列表方式）⭐补充

不用字典，用**列表**读写。适合无表头或纯顺序数据。

```python
import csv

# 写（列表方式）
with open('03.csv', 'w', newline='', encoding='utf-8') as f:
    writer = csv.writer(f)
    writer.writerow(["姓名", "年龄", "性别"])   # 表头
    writer.writerow(["小王", "18", "男"])        # 数据
    writer.writerows([                          # 批量
        ["小李", "23", "女"],
        ["小兰", "22", "女"],
    ])

# 读（列表方式）
with open('03.csv', 'r', newline='', encoding='utf-8') as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)        # ['小王', '18', '男']
        print(row[0])     # 按索引取值
```

**DictWriter vs writer 对比**：

| | DictWriter/DictReader | writer/reader |
|------|:--:|:--:|
| 数据形式 | 字典 | 列表 |
| 取值方式 | `row["姓名"]`（按名） | `row[0]`（按索引） |
| 可读性 | ✅ 高 | ❌ 低 |
| 字段顺序 | fieldnames 控制 | 列表顺序 |
| 适用 | 有表头、字段多 | 无表头、简单数据 |

## 五、关键细节补充⭐

### 1. `newline=''` 为什么必须写

```python
# ✅ 正确：newline=''
with open('02.csv', 'w', newline='', encoding="utf-8") as f:
    ...

# ❌ 不写：Windows 下每行之间会多一个空行
with open('02.csv', 'w', encoding="utf-8") as f:
    ...
```

**原因**：csv 库自己会写 `\r\n` 换行，而 Windows 的文本模式 `open()` 又会把 `\n` 转成 `\r\n`，导致变成 `\r\r\n`（多一个空行）。加 `newline=''` 告诉 open 不要自动转换换行，交给 csv 库处理。**Linux/Mac 也建议加，保持一致**。

### 2. 追加写入 `"a"` 模式

你的电影案例用 `"w"`（覆盖写），如果分批爬取想追加：

```python
# "a" 追加：不清空，在末尾继续写
with open('movies.csv', 'a', newline='', encoding='utf-8') as f:
    writer = csv.DictWriter(f, fieldnames=["电影名", "评分"])
    # ⚠️ 追加时不要 writeheader()，否则每批都写一次表头！
    writer.writerow({"电影名": "新电影", "评分": "8.5"})
```

> ⚠️ **追加模式不要写表头**：`"a"` 模式下 `writeheader()` 会在每次追加时都插一行表头，污染数据。只有第一次创建文件或 `"w"` 覆盖时才写表头。

### 3. 中文编码：`utf-8` vs `utf-8-sig`

```python
# utf-8：标准编码，Python/IDE 读正常，但 Excel 打开会乱码
with open('movies.csv', 'w', encoding='utf-8') as f: ...

# utf-8-sig：带 BOM 头，Excel 打开中文不乱码 ✅
with open('movies.csv', 'w', encoding='utf-8-sig') as f: ...
```

**原因**：Excel 默认用 GBK 解析 CSV，遇到无 BOM 的 UTF-8 会把中文当乱码。`utf-8-sig` 在文件头加 BOM 标记（`﻿`），Excel 见到 BOM 就知道是 UTF-8。

> 💡 **爬虫存 CSV 建议用 `utf-8-sig`**，方便直接用 Excel 查看爬取结果。你的电影案例用 `utf-8`，Python 读没问题，但 Excel 打开中文会乱码，可改进。

### 4. DictWriter 的 `extrasaction` 参数

```python
# 默认 extrasaction='raise'：字典字段超出 fieldnames 会报错
writer = csv.DictWriter(f, fieldnames=["姓名", "年龄"])
writer.writerow({"姓名": "mo", "年龄": "23", "爱好": "Java"})  # ❌ ValueError: 好不在 fieldnames

# 改成 'ignore'：自动忽略多余字段
writer = csv.DictWriter(f, fieldnames=["姓名", "年龄"], extrasaction='ignore')
writer.writerow({"姓名": "mo", "年龄": "23", "爱好": "Java"})  # ✅ 只写姓名、年龄
```

> 💡 爬虫场景：数据字段可能不固定，`extrasaction='ignore'` 更健壮。

### 5. 自定义分隔符 `delimiter`

```python
# 用 | 分隔（TSV 用 \t）
writer = csv.writer(f, delimiter='|')
# 输出：小王|18|男
```

## 六、CSV 操作速查表

| 操作 | 写法 | 说明 |
|------|------|------|
| 字典写 | `csv.DictWriter(f, fieldnames=...)` | 推荐有表头 |
| 字典读 | `csv.DictReader(f)` | 按字段名取值 |
| 列表写 | `csv.writer(f)` | 无表头/简单 |
| 列表读 | `csv.reader(f)` | 按索引取值 |
| 写表头 | `writer.writeheader()` | DictWriter 专用 |
| 批量写 | `writer.writerows(列表)` | 一次写多行 |
| 追加 | `open(..., 'a', newline='')` | 不写表头 |
| Excel 不乱码 | `encoding='utf-8-sig'` | 带 BOM |
| 忽略多余字段 | `extrasaction='ignore'` | 字段不固定时 |

## 七、电影榜单爬取案例（第 128-133 集）⭐

> 💡 **来自学习者的实战练习**：完整爬取 TMDB（themoviedb.org）高分电影榜单，5 页共 100 部电影详情，存入 CSV。

### 1. 项目架构

```
请求榜单页（5页）
    │
    ├── 第1页：GET 高分电影页
    ├── 第2-5页：POST 分页接口（带筛选参数）
    │
    ▼
解析榜单页 → 获取每部电影的详情链接
    │
    ▼
逐个请求详情页 → xpath 提取 11 个字段
    │
    ▼
攒成字典列表 → csv.DictWriter 批量写入 CSV
```

### 2. 三大函数分工

| 函数 | 职责 | 亮点 |
|------|------|------|
| `get_movie_info(url)` | 爬单个电影详情 | 11 个字段的 xpath 定位 + 空值保护 |
| `save_all_movies(列表)` | 存 CSV | DictWriter + writerows 批量写 |
| `main()` | 主流程 | 翻页 + 遍历 + 串联 |

### 3. 关键技术点剖析

**① 翻页请求（GET + POST 混合）**

```python
for page_number in range(1, 6):        # 5 页 = 100 部
    if page_number == 1:
        # 第1页：普通 GET
        response = requests.get(TMDB_TOP_URL, timeout=60)
    else:
        # 第2-5页：POST 带筛选参数（page={page_number}）
        response = requests.post(TMDB_TOP_URL_PAGE,
                                 data=f"...&page={page_number}&...",
                                 timeout=60)
```

> 💡 很多网站的翻页不是简单改 URL 的 `?page=2`，而是用 POST 提交筛选表单。这里第 1 页 GET、后续页 POST，是真实网站的常见模式。

**② 详情页 xpath 定位（11 个字段）**

```python
# 简单定位：按 id + 层级
movie_names = doc_info.xpath("//*[@id='original_header']/div[2]/section/div[1]/h2/a/text()")

# 取属性值：/@data-percent（评分藏在属性里）
movie_scores = doc_info.xpath("//*[@id='consensus_pill']/div/div[1]/div/div/@data-percent")

# 高级定位：contains() + preceding-sibling（找导演）
movie_directors = doc_info.xpath(
    "//*[@id='original_header']/div[2]/section/div[3]/ol"
    "//p[@class='character' and contains(text(), 'Director')]"
    "/preceding-sibling::p[1]/a/text()"
)
```

> 💡 导演的 xpath 用了 `contains(text(), 'Director')` + `preceding-sibling::p[1]`（找前面一个兄弟节点）——这是 4.1 笔记里没讲到的**轴（axis）**语法，`preceding-sibling` 表示"前面的同级元素"，很高级。

**③ 空值保护（防 xpath 取不到报错）**

```python
# xpath 返回列表，可能为空，直接 [0] 会 IndexError
"电影名": movie_names[0].strip() if movie_names else '',

# 多值字段用 join 拼接
"类型": ','.join(movie_tags) if movie_tags else '',
"导演": ','.join(movie_directors) if movie_directors else '',
```

> 💡 这是爬虫的**核心防御写法**：xpath 返回列表，先判断非空再取 `[0]`，否则用空字符串。电影案例 11 个字段每个都做了保护，非常规范。

**④ CSV 批量存储**

```python
def save_all_movies(all_movies_info):
    with open(MOVIE_LIST_FILE, 'w', newline='', encoding='utf-8') as csvfile:
        writer = csv.DictWriter(csvfile, fieldnames=["电影名","年份","上映时间","类型","时长","评分","语言","导演","作者","宣传语","简介"])
        writer.writeheader()
        writer.writerows(all_movies_info)   # 100 部一次写入
```

### 4. 可改进点

| # | 改进 | 原因 |
|:--:|------|------|
| 1 | `encoding='utf-8'` → `'utf-8-sig'` | Excel 打开中文不乱码 |
| 2 | 加 `headers={"User-Agent":...}` | 防反爬，无 UA 可能被封 |
| 3 | 加 `time.sleep(1)` | 控制频率，别给服务器压力 |
| 4 | 用 `"a"` 模式分批存 | 100 部全爬完才写，中途崩了数据全丢 |
| 5 | 详情请求加 `try/except` | 单个电影失败不该让整个程序崩 |

## 常见坑点

1. **`newline=''` 必须写** — Windows 下不加会产生空行（csv 库已写 `\r\n`，open 又转一次）
2. **Excel 打开 CSV 中文乱码** — 用 `utf-8-sig` 而非 `utf-8`
3. **追加模式别写表头** — `"a"` 模式下 `writeheader()` 每次都插一行表头
4. **xpath 返回空列表直接 `[0]`** — 会 IndexError，必须先判空（电影案例做得很好）
5. **DictWriter 字段超出报错** — `extrasaction='ignore'` 忽略多余字段
6. **翻页不只改 URL** — 很多网站用 POST 提交筛选参数，要抓接口
7. **爬虫没加 User-Agent** — 容易被反爬拒绝（电影案例还没加）
8. **爬太快被封 IP** — 加 `time.sleep()` 控制频率
9. **数据全爬完才写** — 中途崩溃数据全丢，建议分批追加写

## 小结

1. **CSV 两种方式**：原始文件（手动拼逗号，不推荐）vs csv 库（自动处理转义，推荐）
2. **字典方式最推荐**：DictWriter/DictReader，按字段名读写，可读性好
3. **关键细节**：`newline=''` 防空行、`utf-8-sig` 防 Excel 乱码、追加不写表头、空值保护
4. **电影案例**：翻页（GET+POST）→ 详情页 xpath → 空值保护 → CSV 批量存储，是爬虫完整闭环
5. **爬虫存储套路**：攒数据到列表 → DictWriter + writerows 一次写入
