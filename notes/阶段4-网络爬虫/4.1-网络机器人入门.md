## 一、网络机器人概述

### 1. 什么是爬虫

- **是什么**：爬虫（Web Spider）就是一段自动程序，**模拟浏览器去访问网页，把想要的数据抓回来**。像一只蜘蛛在互联网这张大网上爬，遇到有用的就收下。
- **Java 对比**：≈ 用 `HttpClient` 请求网页 + `Jsoup` 解析 HTML。Python 的 `requests` + `lxml` 组合更简洁。

### 2. 爬虫的基本流程

```
1. 发请求   requests.get(url)        → 拿到网页 HTML 文本
2. 解析     lxml / xpath             → 从 HTML 里提取想要的数据
3. 存数据   写文件 / CSV / 数据库     → 持久化保存
```

### 3. robots 协议（爬虫道德）

- 网站根目录下的 `robots.txt` 声明哪些页面**允许**爬、哪些**禁止**爬。
- 例：`https://www.tiobe.com/robots.txt`
- **约定俗成的规范，不是技术强制**，但写爬虫应遵守，避免给对方服务器造成压力。

> ⚠️ 爬虫合法三原则：遵守 robots、控制访问频率（加延时）、不抓取个人隐私/付费数据。

## 二、requests 发送请求

### 1. 基本请求

```python
import requests

# 发送 GET 请求
response = requests.get("https://www.tiobe.com/tiobe-index/")

# response.text —— 响应体（HTML 文本字符串）
print(response.text)

# response.status_code —— 状态码（200 成功）
print(response.status_code)

# response.encoding —— 编码
print(response.encoding)
```

| 属性 | 含义 |
|------|------|
| `response.text` | 响应体文本（自动解码的字符串） |
| `response.content` | 响应体字节流（二进制，图片/视频用） |
| `response.status_code` | HTTP 状态码 |
| `response.encoding` | 编码方式 |
| `response.url` | 最终请求 URL（含重定向后的） |

### 2. 伪装请求头（防反爬）

很多网站会检测请求头，纯 `requests.get()` 可能被识别为爬虫而拒绝。需要伪装成浏览器：

```python
headers = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 ..."
}
response = requests.get(url, headers=headers)
```

> 💡 **User-Agent** 是浏览器身份标识。在浏览器 F12 → Network → 请求头里可以复制自己的 UA。

### 3. Java 对比

| | Python requests | Java HttpClient |
|------|:--:|:--:|
| 代码量 | 3 行 | 7+ 行 |
| GET 请求 | `requests.get(url)` | `HttpClient.send(request, BodyHandlers.ofString())` |
| 响应取文本 | `response.text` | `response.body()` |

## 三、前端网页结构（HTML / CSS / JS）⭐

> 📺 第 123 集。爬虫要解析网页，必须先看懂 HTML 结构。这一节补充前端三剑客的基础知识——**爬虫主要和 HTML 打交道**，CSS/JS 了解即可。

### 1. HTML（骨架）—— 爬虫的核心对象

HTML（HyperText Markup Language）用**标签**描述网页结构，像人的骨架。

```html
<!DOCTYPE html>
<html>
  <head>
    <title>页面标题</title>
    <meta charset="utf-8">
  </head>
  <body>
    <h1>大标题</h1>
    <p>这是一段文字</p>
    <a href="https://xxx.com">链接</a>
    <img src="logo.png">
    <ul>
      <li>列表项1</li>
      <li>列表项2</li>
    </ul>
    <table>
      <thead><tr><th>表头</th></tr></thead>
      <tbody><tr><td>数据</td></tr></tbody>
    </table>
    <div class="box" id="main"><span>嵌套</span></div>
  </body>
</html>
```

**HTML 树状结构**（爬虫解析的本质就是把 HTML 当成一棵树）：

```
html
├── head
│   ├── title
│   └── meta
└── body
    ├── h1
    ├── p
    ├── a
    └── div
        └── span
```

**爬虫常用标签速查**：

| 标签 | 含义 | 爬虫常用场景 |
|------|------|------------|
| `<a href="">` | 超链接 | 抓下一页 URL |
| `<img src="">` | 图片 | 抓图片地址 |
| `<table>` | 表格 | 抓结构化数据（如排行榜） |
| `<tr>` / `<td>` / `<th>` | 行 / 单元格 / 表头 | 表格数据 |
| `<div>` | 块容器 | 大区块定位 |
| `<span>` | 行内容器 | 小片段文字 |
| `<ul>` / `<li>` | 无序列表 / 列表项 | 列表数据 |
| `<p>` | 段落 | 文章正文 |
| `<h1>~<h6>` | 标题 | 标题文字 |

**标签的属性**（爬虫定位元素的关键）：

```html
<div class="modes" id="main" data-mode="work">
<!--     ↑class   ↑id      ↑自定义属性 -->
```

| 属性 | 含义 | xpath 用法 |
|------|------|-----------|
| `class` | 样式类名（可多个，空格分隔） | `@class`、`contains(@class, "x")` |
| `id` | 唯一标识 | `@id="main"` |
| `href` | 链接地址 | `@href` |
| `src` | 资源地址 | `@src` |
| `style` | 内联样式 | `@style` |
| `data-*` | 自定义数据属性 | `@data-mode` |

> ⚠️ **class 多值陷阱**：`class="mode-btn work active"` 是三个类名。xpath 写 `@class="work"` 会匹配失败（要整个字符串相等），必须用 `contains(@class, "work")`。

### 2. CSS（皮肤）—— 爬虫了解即可

CSS（Cascading Style Sheets）控制网页**长什么样**（颜色、大小、布局），像人的皮肤衣服。

```css
/* 选择器 + 样式声明 */
h1 { color: #5a8a7a; }              /* 标签选择器 */
.modes { padding: 10px; }           /* class 选择器，用 . */
#main { width: 100%; }              /* id 选择器，用 # */
```

- 爬虫一般不解析 CSS，但 **class 名常作为定位元素的依据**（如 `//div[@class="modes"]`）。
- 你代码里的 `h1[@style='color: #5a8a7a']` 就是匹配内联 CSS 样式。

### 3. JavaScript（行为）—— 动态内容的难点

JS（JavaScript）控制网页**行为**（点击响应、动态加载数据），像人的肌肉神经。

```javascript
// 点击按钮切换模式
button.onclick = function() {
    loadNewData();   // 用 AJAX 动态请求新数据
}
```

**对爬虫的影响**：
- **静态网页**：数据直接在 HTML 源码里，`requests` + xpath 就能抓（你这次的 tiobe 排行榜就是）。
- **动态网页**：数据由 JS 在加载后通过 AJAX 请求获取，**HTML 源码里没有**。`requests` 抓不到，需要：
  - 方法 A：在浏览器 F12 → Network → XHR 里找到真实数据接口，直接请求 JSON
  - 方法 B：用 Selenium / Playwright 模拟浏览器执行 JS

> 💡 判断静态/动态：浏览器右键"查看网页源代码"里能搜到数据 = 静态；搜不到 = 动态。

### 4. 前端三剑客总结

| 技术 | 作用 | 类比 | 爬虫关系 |
|------|------|------|---------|
| **HTML** | 结构 | 骨架 | ⭐ 核心，解析对象 |
| **CSS** | 样式 | 皮肤 | 了解，class 用于定位 |
| **JS** | 行为 | 肌肉 | 动态内容需特殊处理 |

## 四、网页解析（lxml）

### 1. 安装 lxml

```bash
pip install lxml
```

### 2. 把 HTML 文本变成可查询的文档对象

```python
from lxml import html

# 方式1：解析网络响应
response = requests.get(url)
doc = html.fromstring(response.text)

# 方式2：解析本地 HTML 文件
with open("resource/花卉一览表.html", "r", encoding="utf-8") as f:
    doc = html.document_fromstring(f.read())
```

**`fromstring` vs `document_fromstring`**：

| 函数 | 行为 |
|------|------|
| `html.fromstring(text)` | 解析 HTML，返回可能是片段或完整文档 |
| `html.document_fromstring(text)` | 强制解析为完整文档（自动补 html/body 包裹） |

> 💡 解析后得到的 `doc` 是一个**元素对象**（Element），可以用 `.xpath()` 方法查询。本质是把 HTML 文本变成了一棵**可遍历的树**。

### 3. 浏览器辅助获取 xpath

- 在浏览器页面右键 → 检查（F12）→ 选中元素 → 右键 → Copy → **Copy XPath**
- 能直接得到如 `/html/body/section/div/article/table[1]/thead/tr/th` 的路径
- ⚠️ 浏览器复制的路径**绝对路径太长太脆弱**（页面结构一变就失效），建议手写相对路径 `//table[@id='top20']//th`

## 五、XPath 常用语法⭐

> 📺 第 125 集。XPath（XML Path Language）是在 HTML/XML 文档里**定位节点**的查询语言，类似数据库的 SQL。

### 1. 路径表达式（最基础）

| 表达式 | 含义 | 示例 |
|--------|------|------|
| `/` | 从根节点选 / 直接子节点 | `/html/body/div` |
| `//` | 从任意位置选后代节点（不管多深） | `//table` 找所有 table |
| `.` | 当前节点 | `./td` 当前元素下的 td |
| `..` | 父节点 | `../tr` |
| `@` | 选属性 | `//@class` |

```python
# 绝对路径（从根开始，/开头）—— 脆弱，不推荐
doc.xpath("/html/body/div/table/thead/tr/th/text()")

# 相对路径（//开头，任意位置）—— 推荐
doc.xpath("//table/thead/tr/th/text()")

# 当前节点下查找（./开头）—— 遍历时常用
for tr in tr_list:
    td = tr.xpath("./td/text()")
```

### 2. 取文本 / 取属性（爬虫最常用）

| 写法 | 含义 | 返回 |
|------|------|------|
| `/text()` | 直接子文本节点 | 列表 `['工作']` |
| `//text()` | 所有后代文本 | 列表（可能含空白） |
| `string(节点)` | 节点内所有文字拼成字符串 | 字符串 `'工作'` |
| `/@属性名` | 取属性值 | 列表 `['work']` |
| `/@*` | 取所有属性的值 | 列表 |

```python
# 取文本
doc.xpath("//button[@data-mode='work']/text()")    # ['工作']
# 取属性
doc.xpath("//td/@class")                            # ['col-en', 'col-zh']
doc.xpath("//*/td/@*")                              # 所有 td 的所有属性值
```

> ⚠️ **xpath() 永远返回列表**，即使只匹配一个。取单个值用 `[0]`：`doc.xpath("//title/text()")[0]`。

### 3. 谓语（方括号筛选）

```python
# 1. 索引（xpath 索引从 1 开始，不是 0！）
doc.xpath("//tr[1]/td/text()")        # 第 1 行
doc.xpath("//tr[3]/td/text()")        # 第 3 行

# 2. last() 函数
doc.xpath("//tr[last()]/td/text()")       # 最后一行
doc.xpath("//tr[last()-1]/td/text()")     # 倒数第二行

# 3. 位置区间
doc.xpath("//tr[position()<=3]/td/text()")    # 前 3 行
```

> ⚠️ **xpath 索引从 1 开始**，这是和 Python 列表（从 0 开始）最大的不同，Java 背景也容易踩。

### 4. 属性匹配

```python
# 有某个属性
doc.xpath("//h1[@style]/text()")                    # 带 style 属性的 h1
# 属性等于某值
doc.xpath("//h1[@style='color: #5a8a7a']/text()")   # style 等于指定值
# 按其他属性
doc.xpath("//table[@id='top20']//th/text()")        # id 为 top20 的表格
doc.xpath("//button[@data-mode='work']/text()")     # data-mode 为 work
```

### 5. 通配符

| 通配符 | 含义 |
|--------|------|
| `*` | 匹配任意元素标签 |
| `@*` | 匹配任意属性 |
| `node()` | 匹配任意节点（含文本节点） |

```python
# * 匹配任意标签：任意标签下的 td[@class='col-en']
doc.xpath("//*/td[@class='col-en']/text()")

# @* 取所有属性值
doc.xpath("//*/td/@*")
```

### 6. 多值 class 的处理（重点）

```python
# HTML: <button class="mode-btn work active">

# ❌ 错误：要求 class 完全等于 "work"（实际值是 "mode-btn work active"）
doc.xpath('//button[@class="work"]')        # 匹配不到！

# ✅ 正确：用 contains() 包含判断
doc.xpath('//button[contains(@class, "work")]')
```

### 7. 多条件 / 或关系

```python
# 多个条件同时满足（and）
doc.xpath("//td[@class='col-en' and @id='x']/text()")

# 或关系（or）
doc.xpath("//td[@class='col-en' or @class='col-zh']/text()")

# 用 | 合并两个路径
doc.xpath("//th/text() | //td/text()")
```

### 8. XPath 常用语法速查表

| 目的 | 写法 |
|------|------|
| 所有某标签 | `//div` |
| 取文本 | `//div/text()` |
| 取属性 | `//div/@class` |
| 按属性筛选 | `//div[@id='main']` |
| 多值 class | `//div[contains(@class, 'box')]` |
| 第 N 个 | `//tr[2]`（从1开始） |
| 最后一个 | `//tr[last()]` |
| 前 N 个 | `//tr[position()<=3]` |
| 任意标签 | `//*/td` |
| 当前节点下 | `./td` |
| 或合并 | `//th \| //td` |

## 七、完整爬虫代码模板

结合三个示例，标准爬虫结构如下：

```python
import requests
from lxml import html

# 1. 准备 URL 和请求头（防反爬）
url = "https://www.tiobe.com/tiobe-index/"
headers = {"User-Agent": "Mozilla/5.0 ..."}

# 2. 发请求
response = requests.get(url, headers=headers)
response.encoding = "utf-8"   # 防止中文乱码

# 3. 解析成文档对象
doc = html.fromstring(response.text)

# 4. xpath 提取数据
th_list = doc.xpath("//table[@id='top20']//th/text()")
tr_list = doc.xpath("//table[@id='top20']//tbody/tr")
for tr in tr_list:
    row = tr.xpath("./td/text()")   # 两步法取每行
    print(row)

# 5. 存数据（后续 CSV 章节学）
# ...
```

## 常见坑点

1. **xpath 索引从 1 开始** — `tr[1]` 是第一行，不是 `tr[0]`（和 Python/Java 数组不同）
2. **xpath() 返回列表** — 即使匹配一个也是列表，取值要 `[0]`
3. **多值 class 不能用 `=`** — `@class="work"` 匹配失败，要用 `contains(@class, "work")`
4. **绝对路径太脆弱** — 浏览器复制的 `/html/body/...` 路径，页面结构微调就失效，优先用 `//标签[@属性]` 相对路径
5. **`/text()` vs `//text()`** — `/text()` 只取直接子文本，`//text()` 取所有后代文本（可能含空白字符）
6. **中文乱码** — `response.encoding = "utf-8"` 或 `response.encoding = response.apparent_encoding`
7. **被反爬封禁** — 不加 User-Agent 可能被拒；访问太快会被封 IP，加 `time.sleep()`
8. **动态网页抓不到** — `requests` 抓的是 HTML 源码，JS 动态加载的数据不在里面，需找接口或用 Selenium
9. **本地文件路径** — 示例用相对路径 `resource/xxx.html`，依赖工作目录，建议后续改 `os.path` 绝对路径

## 小结

1. **爬虫三步走**：`requests` 发请求 → `lxml` 解析 → 存数据
2. **前端三剑客**：HTML 是结构（爬虫核心对象）、CSS 是样式（class 用于定位）、JS 是行为（动态内容需特殊处理）
3. **XPath 核心**：`//标签[@属性]` 定位、`/text()` 取文本、`/@属性` 取属性、`[n]` 索引（从1开始）、`contains()` 处理多值 class
4. **表格爬取套路**：先 `//tr` 取行集合，再循环 `./td/text()` 取每行单元格
