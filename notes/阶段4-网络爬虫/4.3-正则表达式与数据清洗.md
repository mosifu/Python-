## 一、正则表达式是什么

- **是什么**：正则表达式（Regular Expression）是一套**用符号描述字符串模式**的规则，用来在文本里**匹配、提取、替换**符合规则的内容。
- **Java 对比**：≈ Java 的 `Pattern` / `Matcher`。语法几乎一样，但 Python 用 `re` 模块更简洁——`re.findall` 一行替代 Java 的 `while(matcher.find())` 循环。
- **为什么爬虫需要**：爬下来的数据是"脏"的——年份可能是 `(1994)`、时长可能是 `2h22m`、日期可能带后缀 `(US)`。正则负责把这些**清洗成干净格式**。

## 二、re 三大函数（第 134 集）

| 函数 | 作用 | 返回 | 示例 |
|------|------|------|------|
| `re.match(pattern, s)` | **只从字符串开头**匹配 | Match 对象 或 None | 开头正好是手机号 → 匹配 |
| `re.search(pattern, s)` | 在**整个字符串**里找**第一个**匹配 | Match 对象 或 None | 任意位置找第一个手机号 |
| `re.findall(pattern, s)` | 找**所有**匹配 | 字符串列表 | 提取所有手机号 |

### 1. re.match —— 从开头匹配

```python
import re

pattern_phone = r"1[3-9]\d{9}"   # 手机号：1开头 + 第二位3-9 + 9位数字

s1 = "18809090000是我的手机号..."   # 开头就是手机号
s2 = "我的手机号是18809090000..."   # 开头不是手机号

result = re.match(pattern_phone, s1)
if result:                       # match 失败返回 None，先判断再取值
    print(result.group())        # '18809090000'
    print(result.span())         # (0, 11) 匹配的索引区间
    print(result.start())        # 0
    print(result.end())          # 11

re.match(pattern_phone, s2)      # None（s2 开头不是手机号）
```

> 💡 **`re.match` 只看开头**——即使字符串中间有手机号也不匹配。这正是 s1 能匹配、s2 匹配不到的原因（代码里用两个字符串对比演示了这一点）。

### 2. re.search —— 找第一个

```python
res = re.search(pattern_phone, s2)
if res:
    print(res.group())   # '18809090000'（s2 里第一个手机号）
```

### 3. re.findall —— 找全部（爬虫最常用）

```python
all_phone = re.findall(pattern_phone, s1)
print(all_phone)   # ['18809090000', '1880008888', ...] 返回列表
```

> ⚠️ **三函数差异是高频考点**：match 看开头、search 找第一个、findall 找全部。爬虫清洗数据 90% 用 `re.search`（提取某字段）或 `re.findall`（提取全部）。

## 三、r 原始字符串

```python
pattern = r"1[3-9]\d{9}"
#          ↑ r 前缀
```

> 💡 **`r"..."` 表示原始字符串**：字符串里的 `\` 不再被 Python 转义，`\d` 就是字面意义的"反斜杠+d"，直接交给正则引擎解释。**写正则必须加 `r`**，否则 `"\d"` 里的 `\d` 会被 Python 先处理（可能报错或含义错误）。

## 四、正则基础语法（第 135 集）

### 1. 量词（匹配次数）

| 符号 | 含义 | 示例 |
|:--:|------|------|
| `*` | 匹配**任意个**（0个或多个） | `188.*` 匹配 `188` 开头任意内容 |
| `?` | 匹配 **0个或1个**（最多一次） | `188.?` 匹配 `188` 加最多1个任意字符 |
| `+` | 匹配 **1个或多个**（最少一次） | `188.+` 匹配 `188` 加至少1个任意字符 |

```python
re.findall(r"188.*", s1)   # 匹配所有"188开头"的片段
re.findall(r"188.?", s1)   # '1880' '188' '1880' ...
re.findall(r"188.+", s1)   # 要求 188 后面至少跟一个字符
```

### 2. \d 数字与花括号量词

| 写法 | 含义 |
|------|------|
| `\d` | 匹配一个数字 |
| `\d{8}` | 匹配**恰好 8 位**数字 |
| `\d{6,10}` | 匹配 **6 到 10 位**数字 |
| `\d{6,}` | 匹配**至少 6 位**数字 |

```python
re.findall(r"188\d{8}", s1)        # '188' + 恰好8位数字
re.findall(r"155\d{6,10}", s1)     # '155' + 6到10位数字
re.findall(r"155\d{6,}", s1)       # '155' + 至少6位数字
```

### 3. 字符集 []

| 写法 | 含义 |
|------|------|
| `[38]` | 第二位是 3 **或** 8 |
| `[^38]` | 第二位**不是** 3 或 8（`^` 在 `[]` 内表示取反） |
| `[3-9]` | 范围：3 到 9 任意一个 |

```python
re.findall(r"1[38]\d{8}", s1)      # 匹配 13xxxxxxxxx 或 18xxxxxxxxx
re.findall(r"1[^38]\d{8}", s1)     # 第二位不是 3 或 8
re.findall(r"1[3-9]\d{8}", s1)     # 第二位是 3-9（手机号常用）
```

### 4. 锚点 ^ 和 $

| 符号 | 含义 |
|------|------|
| `^` | 从**字符串开头**匹配 |
| `$` | 匹配到**字符串结尾** |

```python
re.findall(r"^1[3-9]\d{9}", s1)    # 必须字符串开头就是手机号
re.findall(r"^1[3-9]\d{9}$", s1)   # 整个字符串恰好是一个手机号
```

> ⚠️ **`^` 两种含义**：在 `[]` 外面是"开头锚点"，在 `[]` 里面是"取反"。`[^38]` = 不是3或8。

### 5. \w 单词字符

```python
re.findall(r"\w+@\w+\.\w+", s1)    # 匹配邮箱 python666@163.com
```

- `\w` 匹配单词字符：字母、数字、下划线、**中文等其他语言字符**
- 加 `re.ASCII` 参数后只匹配 ASCII 字符（`a-zA-Z0-9_`）

> ⚠️ **写正则必须转义点号**：邮箱里的 `.` 用 `\.`，因为单独的 `.` 表示"任意字符"。

### 6. 分组捕获 ()

```python
s2 = "现在的时间是2026年-02月-06日 10h:05m:25s"

# 不加分组：返回完整匹配的列表
re.findall(r"\d{4}-\d{2}-\d{2}", s2)   # ['2026-02-06']

# 加分组：每组内容打包成元组
re.findall(r"(\d+)h:(\d+)m:(\d+)s", s2)  # [('10', '05', '25')]

# search + group(序号)：提取指定分组
re.search(r"(\d+)h:(\d+)m:(\d+)s", s2).group(3)  # '25'（第3组，秒）
```

| 用法 | 返回 |
|------|------|
| `group()` | 整个匹配 |
| `group(1)` `group(2)` | 第 1、2 组 |
| `group(3)` | 第 3 组 |

> 💡 分组是**数据清洗的核心武器**：不是取整段，而是从一段里精准抠出需要的部分（如从 `2h22m` 里分别抠出 `2` 和 `22`）。

## 六、电影榜单案例数据清洗完善（第 136 集）⭐

> 💡 **来自学习者的实战练习**：昨天的电影榜单程序今天加了 3 个清洗函数，把脏数据（`(1994)`、`1994-09-23 (US)`、`2h22m`）清洗成干净格式。

### 1. 清洗思路：三个函数专治三个字段

| 函数 | 输入（脏） | 输出（干净） | 正则 |
|------|-----------|------------|------|
| `get_movie_year` | `(1994)` | `1994` | `re.search(r"\d{4}", year)` |
| `get_movie_start` | `1994-09-23 (US)` | `1994-09-23` | `re.search(r"\d{4}-\d{2}-\d{2}", start)` |
| `get_movie_times` | `2h22m` | `142m` | 分组 `(\d+)h` + `(\d+)m` → `2*60+22` |

### 2. 逐函数剖析

**① 年份清洗：提取 4 位数字**

```python
def get_movie_year(movie_years: list) -> str:
    year = movie_years[0].strip() if movie_years else ''   # 空值保护（沿用4.2习惯）
    if year:
        year_match = re.search(r"\d{4}", year)   # 从 "(1994)" 里抠出 "1994"
        return year_match.group() if year_match else ''
    else:
        return year
```

> 💡 流程：先判空 → `re.search` 找第一处 4 位数字 → `group()` 转字符串 → 找不到返回空串。**`re.search` + 判空 + `group()` 是清洗函数的标准三步**。

**② 上映时间清洗：提取日期**

```python
def get_movie_start(movie_starts: list) -> str:
    start = movie_starts[0].strip() if movie_starts else ''
    if start:
        start_match = re.search(r"\d{4}-\d{2}-\d{2}", start)
        # 从 "1994-09-23 (US)" 里抠出 "1994-09-23"
        return start_match.group() if start_match else ''
    else:
        return start
```

**③ 时长清洗：小时转分钟（分组捕获实战）**

```python
def get_movie_times(movie_times: list) -> str:
    time = movie_times[0].strip() if movie_times else ''
    if not time:
        return time
    hour = re.search(r"(\d+)h", time)     # 从 "2h22m" 抠小时 "2"
    mint = re.search(r"(\d+)m", time)     # 抠分钟 "22"
    hour_res = int(hour.group(1)) if hour else 0    # group(1) 取第1组数字
    min_res = int(mint.group(1)) if mint else 0
    if not min_res and not hour_res:
        return ''
    movie_time = hour_res * 60 + min_res  # 2*60+22 = 142
    return f"{movie_time}m"               # "142m"
```

> 💡 **三个清洗函数共用同一套"清洗模式"**：判空保护 → re.search 提取 → group 转字符串 → 兜底返回空。学会这套模式，任何字段清洗都是套路。
> 💡 **时长用了 `group(1)`** 而不是 `group()`：因为 `(\d+)h` 里 `h` 也在匹配结果里（`"2h"`），`group(1)` 才能只取数字 `2`。

### 3. 主程序如何接入清洗

```python
movie_info = {
    "电影名": movie_names[0].strip() if movie_names else '',
    "年份": get_movie_year(movie_years),        # 清洗 (1994) -> 1994
    "上映时间": get_movie_start(movie_starts),  # 清洗 1994-09-23 (US) -> 1994-09-23
    "类型": ','.join(movie_tags) if movie_tags else '',
    "时长": get_movie_times(movie_times),       # 清洗 2h22m -> 142m
    ...
}
```

> 💡 清洗函数直接替换原来的 `movie_years[0].strip()`，**接入点清晰**，主逻辑几乎没变——这是"提取字段 + 清洗字段"分离设计的优点。

### 4. 本次代码的亮点

1. **三个清洗函数都用了类型标注**（`movie_years: list -> str`）——昨天报告建议"恢复类型标注"，今天就落实了，值得肯定！
2. **空值保护贯穿始终**：每个函数先判空再处理，和 4.2 的 11 字段空值保护一脉相承
3. **清洗函数独立成函数**：可复用、可测试，比写在主逻辑里清晰
4. **`if not min_res and not hour_res: return ''`**：两个都取不到就返回空，边界处理完整

## 常见坑点

1. **`re.match` 只匹配开头** — 想找任意位置要用 `re.search`
2. **`re.findall` 返回列表** — 想取单个值用 `re.search(...).group()`
3. **写正则忘加 `r`** — `"\d"` 会被 Python 转义出错，必须 `r"\d"`
4. **`.` 是任意字符** — 匹配点号本身要 `\.`
5. **`^` 双重含义** — 外面是开头锚点，`[]` 内是取反
6. **`group()` vs `group(1)`** — 带分组的 pattern 用 `group(1)` 取分组，`group()` 返回含符号的完整匹配
7. **`re.search` 不判空** — 匹配失败返回 None，直接 `.group()` 会 `AttributeError`
8. **正则匹配但没清洗干净** — 先 print 看看 `re.search` 到底匹配到了什么，再写 group 提取
