# Python 跟练代码（黑马课程）

> 跟随 B 站「黑马程序员 Python+AI 零基础入门到大神」课程（BV1sHU9BmEne，185集）**边看视频边敲的练习代码**，记录每一集的学习实战过程。

> 📌 **分支说明**：`code` 分支存放**跟着视频敲的原始练习代码**；结构化笔记和示例在 [`learn`](https://github.com/mosifu/Python-/tree/learn) 分支；AI 学习工具链配置在 [`main`](https://github.com/mosifu/Python-) 分支。

---

## 🎯 解决什么问题

看视频学编程最大的陷阱是"眼睛会了手不会"。本分支记录**跟着视频逐行敲出的练习代码**，用于：

1. **动手验证**：每个知识点都有对应的实战代码，边看边敲，把知识变成肌肉记忆
2. **进度留痕**：按课程集数编号的代码文件，清晰记录学到哪一集、练过什么
3. **Java 对比实践**：在 Java 基础上敲 Python 代码，快速发现语法差异（`elif`、`and/or`、`self`、无 `new` 等）

## 🛠️ 安装方法

### 前置条件

- [Python 3.10+](https://www.python.org/downloads/)（match 语法、`|` 联合类型需要 3.10+）
- [Git](https://git-scm.com/)

### 步骤

```bash
# 1. 克隆仓库
git clone https://github.com/mosifu/Python-.git
cd Python-

# 2. 切换到 code 分支（跟练代码所在分支）
git checkout code

# 3. 验证 Python 环境
python --version   # 需要 3.10+

# 4. 运行任意练习代码（无需安装依赖，只用标准库）
python "day260711_Py/第二章/22.异常处理.py"
```

> 部分练习文件需要交互式输入（`input()`），运行后会等待用户输入，输入对应数据即可看到结果。

## 📖 使用方法

### 方式1：直接运行练习代码

```bash
# 运行不依赖输入的练习（如异常处理）
python "day260711_Py/第二章/22.异常处理.py"

# 运行需要输入的练习（如运算符计算，会等待输入）
python "day260711_Py/第二章/4.运算符.py"
# 按提示输入后回车，例如：请输入一个整数 15
```

### 方式2：结合 AI 工具链学习

```
看视频  ->  跟着敲代码（存到本分支）  ->  发送「生成笔记」
                                       ->  发送「帮我复盘今天的学习」
```

把跟练代码发送给 Claude Code 后：

- **「生成笔记」**：自动分析代码，生成结构化笔记（含 Java 对比表）到 learn 分支的 `notes/`
- **「帮我复盘」**：评估代码质量、掌握度，生成复盘报告和练习题
- **「批改练习」**：批改每日练习题，逐题反馈对错

## 📝 输入输出示例

### 示例1：运行异常处理练习（无需输入）

**输入**：

```bash
python "day260711_Py/第二章/22.异常处理.py"
```

**输出**：

```
------------------------------
程序出错,异常信息: 'str' object has no attribute 'hello'
释放资源~
fun1...running...
fun2...running...
fun3...running...
程序出错,请联系管理人员,错误信息: name 'my_color' is not defined
```

演示了多异常捕获（`except Exception as e`）、`finally` 块、异常沿调用链传递（fun1→fun2→fun3）。

### 示例2：运行运算符练习（需要输入）

**输入**：

```bash
python "day260711_Py/第二章/4.运算符.py"
```

**输出**（用户输入 `15` 后）：

```
请输入一个整数 15
输入数字15不在10-20之间吗?    False
```

演示了 `input()` + `int()` 类型转换 + `and`/`or` 逻辑运算符 + f-string 输出。

### 示例3：运行购物车系统（OOP 版，交互菜单）

**输入**：

```bash
python "day260711_Py/第二章/20.面向对象基础案例1.py"
```

**输出**（用户依次操作 1→4→5）：

```

# # # # # # # # # # # # # # # # # # # # # # # # # # # # # #
# 1.添加购物车    2.修改购物车    3.删除购物车    4.查询购物车    5.退出系统  #
# # # # # # # # # # # # # # # # # # # # # # # # # # # # # #

请输入要执行的操作(1-5): 1
请输入商品名称: 苹果
请输入商品价格: 5.5
请输入商品数量: 3
商品添加成功~

请输入要执行的操作(1-5): 4
商品名称:苹果, 商品价格:5.5, 商品数量:3
```
